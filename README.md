# 2D Gravitational Poisson Solver & Astrophysical Jeans Collapse

A high-performance computational astrophysics simulation modeling the gravitational potential, field vector dynamics, and dynamical Virial stability of self-gravitating interstellar gas clouds. 

---

##Development Roadmap & Version History

This repository documents an iterative engineering and scientific workflow, scaling from an exploratory prototype to a high-performance C++ solver:

* **[x] v1.0 (Python Baseline):** Standard Gauss-Seidel iterative relaxation solver with Dirichlet boundary conditions and Virial Jeans stability analysis.
* **[x] v1.1 (Python Optimization):** Accelerated via Successive Over-Relaxation (SOR) with a dynamically calculated optimal relaxation parameter ($\omega$).
* **[x] v1.1 (C++ HPC Migration):** Rewritten for high-performance computing using a cache-efficient 1D flat-vector architecture (`std::vector<double>` with row-major `i * N + j` indexing) and `-O3` compiler optimization.

##Scientific & Numerical Foundations

### 1. The Gravitational Poisson Equation
In Newtonian gravity, the gravitational potential $\Phi(x, y)$ generated by a continuous mass density distribution $\rho(x, y)$ satisfies the Poisson equation:

$$\nabla^2 \Phi = \frac{\partial^2 \Phi}{\partial x^2} + \frac{\partial^2 \Phi}{\partial y^2} = 4\pi G \rho$$

### 2. Mass Density Distribution
The molecular cloud core is modeled as an axisymmetric Gaussian mass profile on a domain of side length $L$:

$$\rho(r) = \frac{M}{2\pi \sigma^2} \exp\left(-\frac{r^2}{2\sigma^2}\right)$$

### 3. Virial Stability Analysis
The solver evaluates the global Virial theorem to determine whether a cloud undergoes runaway gravitational collapse or thermal dispersion:
* **Gravitational Binding Energy ($\vert{}W\vert{}$):** Computed via matter potential and field vector gradients.
* **Thermal Kinetic Energy ($2K_{\text{th}}$):** Derived from the user-defined isothermal sound speed ($c_s$).
* **Critical Jeans Threshold:** Compares internal pressure support against self-gravity.

## Performance & Language Evolution: Why C++ v1.1?

While the initial Python implementations (v1.0 and v1.1) provide clean analytical transparency, interpreted languages introduce heavy loop overhead when scaling to fine resolution grids (for N=1000, v1.1 took about 3 hours). 

To model large astrophysical domains effectively, **v1.1 was migrated to C++**:
* **Memory Layout:** Replaced high-overhead structures with a flat contiguous `std::vector<double>`, ensuring cache-locality and zero pointer-chasing.
* **Hardware Optimization:** Compiled natively via `g++` with `-O3` flags, allowing the CPU to utilize internal registers and vector pipelines.
* **Benchmark Results:** On a dense **$1000 \times 1000$ grid ($1,000,000$ nodes)**, the C++ SOR engine successfully converges in **$\sim 4,200$ iterations** within seconds (~27 seconds), achieving target residuals under $10^{-5}$ where standard interpreted loops would bottleneck.

How to compile and run (C++)
To run the high-performance C++ solver locally:
# Compile with maximum -O3 optimization
g++ cpp/poisson_astro_SOR.cpp -o solver.exe -O3
# Execute the binary
./solver.exe

Enter your desired grid dimension (e.g., 1000), total mass (50), and isothermal sound speed (0.5) when prompted to simulate cloud collapse dynamics.
